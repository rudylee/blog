Orca

Nov 22, 2026 in [[AI]]
3 min read

This weekend I finally set up Orca properly. After two days with it, I like it a lot more than the tools I use at work. It also got me thinking about what the real bottleneck is when working with AI.

I use something similar at work, an ADE (agentic development environment) that connects to Claude Code and Codex through ACP (the Agent Client Protocol). It works fine, but the UI is too busy and it has a lot of features I never touch.

I ended up building my own small UI on top of it, basically a simple todo list app for controlling it.

What I like about Orca

  • Simplicity. The UI is a lot cleaner. There’s less on screen, so there’s less to think about.
  • GitHub integration. It pulls in the status of my pull requests.
  • An issues list per project, so I can see what’s waiting without leaving the app.
  • Automations. I’ve started using these and will keep experimenting.
  • The mobile app. I’ve got my Mac running all the time, even with the lid closed, so I can check in on sessions from my phone.

It’s early days, though. I haven’t used it across many projects yet and at work I’m constantly jumping between several projects at once. That’s the real test, and I can’t compare the two properly until Orca has been through it.

What I’ll steal for work

Orca has given me ideas for my work setup. The main one is a single place to see everything, with sessions, pull request status and issues all together. That’s the direction I want to take my own UI at work.

The real problem: attention

The biggest problem I have working with AI right now is attention. When I have too many sessions running, I can’t keep track of them all and I don’t think any UI can fix that.

What I think helps is prioritising properly. You don’t want every session open all the time. You want a way to focus on what actually matters today and let the rest wait. For me that means a daily review, something I go through every single day to decide what deserves my attention.

This is basically what David Allen describes in Getting Things Done. Every running session is an “open loop” that quietly takes up attention. His answer is a trusted system and a regular review. He does it weekly, but with AI sessions moving this fast, I think it needs to be daily.

This is why I have a prioritise shortcut on my work UI so I can snooze or hide the things that aren’t important right now.

What’s next

Overall my first impression of Orca is good. I’ve got some personal workflows I want to run through it and I might write a follow up once I’ve used it for longer.
