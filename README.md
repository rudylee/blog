# Blog

My personal blog. Built with [Hugo](https://gohugo.io/) and [hyde-hyde](https://github.com/htr3n/hyde-hyde) template.

# Add new blog post

```
hugo new posts/blog-title.md
```

# Run the server

```
hugo server -D
```

# Migrate posts to Obsidian

One-off script that copies every post into an Obsidian folder (YAML
properties, images in `attachments/<post>/`, relative links). The `slug`
property is kept as-is and is what decides the published URL.

```
python3 scripts/migrate_to_obsidian.py --out ~/path/to/Vault/Blog
```

To keep the old images in the vault's existing attachment folder instead of
`Blog/attachments/`, add `--attachments-out ~/path/to/Vault/Attachments/blog`.

Needs Python 3.11+. It refuses to write into a non-empty folder unless
`--force` is given, and exits non-zero if any slug or image link is broken.

# Publish from Obsidian

Posts are written in the Obsidian `Blog/` folder. Only notes with
`publish: true` (and the attachments they reference) are exported.

```
export BLOG_VAULT_DIR=~/path/to/Vault/Blog
python3 scripts/publish.py --check       # validate only
python3 scripts/publish.py --no-commit   # export + hugo build, review the diff
python3 scripts/publish.py               # export, build, commit and push
```

A new post needs these properties:

```yaml
---
title: My New Post
date: 2026-11-07
slug: 2026/11/07/my-new-post
tags: [obsidian]
publish: true
---
```

`content/posts/` and `static/attachments/` are generated by the script; edit
posts in Obsidian, not here.

Images can live in the blog folder or in the vault's normal attachment folder:
the script reads that folder from `.obsidian/app.json`, so no Obsidian settings
need to change. Only images that published posts embed are copied. Override
with `--attachments DIR` (or `$BLOG_ATTACHMENTS_DIR`) if needed.

# Theme

The hyde-hyde theme is a git submodule pinned to the 2019 version
(`git submodule update --init` after cloning). It is not edited directly;
fixes live in this repo and override the theme's files:

- `layouts/` — compatibility fixes for current Hugo (removed Google Analytics
  and Disqus settings, homepage post list, stylesheet URLs, highlight check)
- `assets/scss/hyde-hyde/` — the 2019 customisations (wider content column,
  mobile menu icon paths)

Tested with Hugo 0.142.
